# 住まい体験ウォークスルー

住所を入れると、国土地理院の地図データからまわりの建物と道路を作り、
その中に家を建てて、目線で歩きながら日当たり・室温・音を確かめられます。

## 置き方
この3つのファイルを、同じフォルダのままウェブサーバーに置いてください。
  index.html / town.js / house.glb
GitHub Pages なら、リポジトリに入れて公開するだけで動きます。
パソコンでファイルを直接ダブルクリックして開く方法では動きません(ウェブサーバー経由で開く必要があります)。

## 外部から読み込むもの
・国土地理院: 建物・道路・住所検索(入力した住所は検索のため国土地理院に送られます)
・jsDelivr: 3D表示の部品(three.js)
・Google Fonts: 文字

## 出典
国土地理院(基盤地図情報・地理院タイル)
建物の配置と道路は地図データどおりですが、建物の高さと屋根の形は面積からの仮定です。
塀・電柱・庭木・土地の高低差は入っていません。室温は簡易計算で、設計用の計算ではありません。

## 最初に表示される場所
index.html の中の DEFAULT_PLACE(緯度・経度・表示名)で決めています。
