# 机上ドローンショー AR

iPhoneのARで、机の上に光の粒のドローンショーを実寸で飛ばすWebアプリです。
株式会社ルックアップ（ルックアップドローン）

## 使い方

1. iPhoneのSafariでページを開く
2. 「ショーの流れ」で形（文字・ドローン・ハート・星・花火・球体・画像）と色を選ぶ
3. 「ARで机に置く」を押し、机の天板にカメラを向ける

離陸と着陸は自動で入り、ショーはループ再生されます。iPhoneを机の高さまで下げると、見上げる視点で楽しめます。

## 机サイズの調整

| 項目 | 範囲 | 初期値 |
|---|---|---|
| 機数 | 60〜1000機 | 300機 |
| ショーの幅 | 15〜50cm | 30cm |
| 光の粒 | 2〜8mm | 4mm |
| 光のにじみ | 0〜100 | 75 |
| 1シーンの長さ | 2〜7秒 | 3.5秒 |

AR表示は実寸固定です（ピンチで大きさは変わりません）。

## 仕組み

- プレビュー：three.js（ブルームで光のにじみを表現）
- AR：AR Quick Look用のUSDZをブラウザ内で生成
  - 「まとめて動かす（軽い）」：60機ずつを1つの部品にまとめ、UsdSkelの骨組みで1機ずつ動かす。1000機でも部品は約100個
  - 「1機ずつ（従来）」：ドローンごとに部品を作る方式。まとめ方式が動かない端末向け

## ファイル

- `index.html` — 画面とプレビュー
- `core.js` — 形状の点配置、タイムライン、USDZ書き出し

# 防災ドローンポート AR（`bousai-port/`）

崖崩れ・津波をボタンで起こすと、無人のドローンポートからドローンが自動で出動し、現場を確認して帰還・充電するまでを、iPhoneのARジオラマで体験できます。

- 遊び方：ARで置いたら手前の「崖崩れ発生」「津波発生」をタップ → 真ん中の「ドローン出動」をタップ
- 置く大きさ：机 40cm／標準 60cm／床 90cm
- 仕組み：AR Quick Lookのタップ動作（Preliminary Behaviors）で、1本のアニメーションを区間ごとに再生
- ポートは実在の製品を写したものではないオリジナルデザイン

# いま・つぎ スケジュール（`schedule/`）

イベント現場でスマホをちらっと見たときに「いま何をやっていて、次は何時から何か」がすぐわかる進行アプリです。

- 開いた画面：日付と時刻、「● いま進行中」の演目名（1行に収まるよう自動で文字サイズを調整）、下に「つぎ」の演目と開始時刻
- 全体表示はステージの進行が基準。担当（出演者・控室／ドローン・ペンライト など）を選ぶと、その担当の予定が基準になります
- 予定の切り替わりは自動（例：9:00ちょうどに次の演目へ）。合間は「次の予定」、終了後は「本日の進行は終了しました」
- 下にスクロールすると、時刻といまの演目が画面の上1/3に残り、その下で進行表を見られます
- 大画面モード：控室や袖に置くタブレット向け
- 予定の入れ方：⚙ →「まとめて入力」に `11/19 16:00-17:10 第一部 #ステージ` のように1行1件で貼り付け。別の端末へは「バックアップ / 読み込み」で移せます

予定データは各端末のブラウザの中だけに保存され、このリポジトリには含めていません。

- 仲間への共有（短いリンク）：`schedule/?e=イベントID#k=鍵` の形。予定は暗号化して `schedule/events/` に置き、鍵はリンクの中だけにあるので、リンクを知らない人は中身を読めません。予定ファイルを更新すると、同じリンクを開くたびに最新になります
- 端末からの共有：⚙ →「仲間に共有するリンクを作る」。予定をリンクの `#data=` 以降に圧縮して入れます（長いリンクになります）
