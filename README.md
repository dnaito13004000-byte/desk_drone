# 机上ドローンショー AR

iPhoneのARで、机の上に光の粒のドローンショーを実寸で飛ばすWebアプリです。
株式会社ルックアップ（ルックアップドローン）

## 使い方

1. iPhoneのSafariでページを開く
2. 「ショーの流れ」で形（文字・ドローン・ハート・星・花火・球体・画像）と色を選ぶ
3. 「ARで机に置く」を押し、机の天板にカメラを向ける

離陸と着陸は自動で入り、ショーはループ再生されます。iPhoneを机の高さまで下げると、見上げる視点で楽しめます。

## 机サイズの調整

| 項目 | 範囲 | 初期値 |
|---|---|---|
| 機数 | 60〜1000機 | 300機 |
| ショーの幅 | 15〜50cm | 30cm |
| 光の粒 | 2〜8mm | 4mm |
| 光のにじみ | 0〜100 | 75 |
| 1シーンの長さ | 2〜7秒 | 3.5秒 |

AR表示は実寸固定です（ピンチで大きさは変わりません）。

## 仕組み

- プレビュー：three.js（ブルームで光のにじみを表現）
- AR：AR Quick Look用のUSDZをブラウザ内で生成
  - 「まとめて動かす（軽い）」：60機ずつを1つの部品にまとめ、UsdSkelの骨組みで1機ずつ動かす。1000機でも部品は約100個
  - 「1機ずつ（従来）」：ドローンごとに部品を作る方式。まとめ方式が動かない端末向け

## ファイル

- `index.html` — 画面とプレビュー
- `core.js` — 形状の点配置、タイムライン、USDZ書き出し

# 防災ドローンポート AR（`bousai-port/`）

崖崩れ・津波をボタンで起こすと、無人のドローンポートからドローンが自動で出動し、現場を確認して帰還・充電するまでを、iPhoneのARジオラマで体験できます。

- 遊び方：ARで置いたら手前の「崖崩れ発生」「津波発生」をタップ → 真ん中の「ドローン出動」をタップ
- 置く大きさ：机 40cm／標準 60cm／床 90cm
- 仕組み：AR Quick Lookのタップ動作（Preliminary Behaviors）で、1本のアニメーションを区間ごとに再生
- ポートは実在の製品を写したものではないオリジナルデザイン
