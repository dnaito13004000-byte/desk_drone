# 効果音フォルダ（dist/sfx）

ゲームはこのフォルダの音源ファイルを、場面ごとにファイル名で読み込みます。
同じ名前のファイルを上書きするだけで音を差し替えられます（コードの変更は不要）。

| 場面 | ファイル名 | 鳴るタイミング |
|---|---|---|
| 召喚 | `summon.mp3` | 手札から神を召喚したとき／神殿の加護で神が現れたとき（相手も） |
| 攻撃 | `attack.mp3` | 攻撃する神カードが引いてから突っ込む瞬間 |
| 命中 | `hit.mp3` | 神カード・神殿・守護に攻撃が当たった瞬間（反撃も） |
| 神殿が砕ける | `shrine-break.mp3` | ヒビの入った神殿カードが砕ける瞬間 |
| 覚醒 | `awaken.mp3` | 場の神カードが覚醒して変化するとき |

- 形式は **mp3を優先**し、mp3が無ければ同じ名前の **.wav** を読みます（例：`hit.wav`）。
- 1ファイルは1〜2秒以内、先頭に無音を入れないのがおすすめです（命中やヒットストップとずれないため）。
- 音量はゲーム内の音量設定（対戦画面のスピーカーボタン）に従います。ミュートもそこで切り替えます。

## いま入っている音について
仮音は2026-11-23に削除しました（不安をあおる音だったため）。いまは効果音なしです。
実録系の効果音（自分で録ったもの、または商用利用可のライセンスの素材）を用意して、同じファイル名で置き換えてください。

## 音を鳴らすには
実録の音源をこのフォルダに置いたうえで、`dist/arena.js` の `SFX_ON=false` を `true` にしてください（対戦画面のスピーカーボタンも、そのとき表示に戻すには `dist/godcards.css` 末尾の `.duel .sndbtn{display:none}` を消します）。

## BGM（2026-11-28 追加）
| 場面 | ファイル名 | 鳴るタイミング |
|---|---|---|
| 通常バトル | `bgm-battle.mp3`（Rivalry's Opening） | 対戦開始から。ループ |
| 最終決戦 | `bgm-final.mp3`（Ultimate Strike） | どちらかの神殿が初めて0枚になり、まだ決着していないとき（既存の「最終決戦」判定）。神殿が割れる演出の瞬間に、通常BGMを止めて曲頭（0秒）から鳴らす。1試合1回、決着までループ |

- 決着したら止まり、リザルトへ。「もう一度戦う」は通常バトルBGMから始まります。
- 音量・ミュートは効果音と共通（対戦画面のスピーカーボタン）。
- 最終決戦BGMは曲頭を落とさないよう、対戦開始時に読み込み・デコードまで済ませています。
- 同じ名前のファイルで上書きすれば曲を差し替えられます。
