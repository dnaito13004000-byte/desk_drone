# 神々の一手 — Claude Code 引き継ぎ
スマホ横持ちを中心にした、召喚と天候コンボの1人用AIカードバトル。主人公を選択し、神を場に出して神殿を攻め、勝利報酬でパックを開ける。

## 起動
展開したこのフォルダで次を実行し、ブラウザで http://localhost:8000 を開く。

    python3 -m http.server 8000 --directory dist

WindowsでPythonランチャーを使う場合は、先頭の python3 を py に替える。ビルドやAPIキーは不要。図鑑・未開封パックは同じブラウザのlocalStorageに保存される。

## 読む順番
1. GAME.md — 現行ルール、構想、プレイ確認手順
2. ART.md — 素材の対応表と画面設計
3. PROMPT.md — Claude Codeへ貼る最初の依頼文

## ソース
dist/index.html はホーム・主人公選択・パック・図鑑・保存と共通UI。dist/arena.js は対戦状態、AI、召喚、攻撃、勝敗。dist/arena.css は戦場のレイアウトと演出。dist/art は戦闘中の画像。2026年11月23日引き継ぎ、公開版のソースコミット 7e8d8a0bb6b6d32829f6672dd3c24a6ddef0a1b9。
